# NOAA Weather Analysis in R

## Project Overview

This project analyses NOAA weather data to study precipitation patterns using statistical and machine learning techniques in R.

## Objectives

- Clean and preprocess NOAA weather data
- Perform exploratory data analysis (EDA)
- Build simple and multiple linear regression models
- Improve models using polynomial regression
- Apply Ridge and Lasso regularization
- Compare model performance using RMSE and R-squared

## Dataset

The dataset contains hourly climatological observations from JFK Airport including:

- Temperature
- Relative humidity
- Wind speed
- Atmospheric pressure
- Precipitation

## Tools and Libraries

- R
- tidyverse
- tidymodels
- ggplot2
- glmnet

## Models Implemented

- Simple Linear Regression
- Multiple Linear Regression
- Polynomial Regression
- Ridge Regression
- Lasso Regression

## Evaluation Metrics

- RMSE
- R-squared

## Results Summary

The project explored multiple regression approaches for precipitation prediction including polynomial regression, Ridge, and Lasso regularization. Detailed findings, methodology discussions, graph interpretations, and model evaluations are available in the `results_and_findings/` folder.
